# Threat Model

`docs/SPEC.md` §39 is the only threat model this project maintains,
including the trust model (§4) it is scoped to, threats to address
(§39.1), and accepted risks (§39.2). `docs/HARDENING_SPEC.md` records
threats a later review found beyond that original scope (HR-001..HR-033)
and how each was closed, tracked against `docs/HARDENING_TODO.md`.

This file exists so a reader who lands on it directly is pointed
somewhere real, not left with a 404 — it is not a second copy of the
reference kept in parallel with `docs/SPEC.md`/`docs/HARDENING_SPEC.md`.
